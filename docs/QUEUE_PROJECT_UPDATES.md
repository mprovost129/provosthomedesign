# Add an update to an existing project

In the staff Work queue, expand **Add work from a phone call or email**.
Search by project number, name or address, then choose **Update an existing project**.
Completed projects are included. Selecting a project loads its details and changes
the request type to Update. Review or replace the description and service, then
choose **Add to queue**.

Alternatively use **Add update** in a request's row. For a completed request,
first change Show to Closed work or All work. This shortcut starts with that
specific request's description and service. The dropdown starts with the latest
nondeleted request on the selected project.

The project name/address come from the current shared project; contact and
billing details come from its source contact's current CRM record when available.
Company associations are retained when a person belongs to several companies.
Missing contact details may still need review. Correcting a field here applies to
the new request snapshot; use the project/client editor for shared profile changes.

Saving creates a separate request ID at the end of the active queue, linked to
the same project and source request. It does not reopen the old request, copy
files, carry forward deadlines or private notes, send email, grant client access,
allocate a project folder number, or create provider records. Use the existing
filing workflow to approve uploads into a project folder.

Switching projects after editing asks whether to load the other project's details
or keep the current draft. Failed lookups retain the draft and block an accidental
save with mismatched details. **Load project details** also supports reloading
without JavaScript; it does not create a request.

Defaults are available only to authenticated staff with both queue viewing and
request creation permission. The public submission form exposes no project list.
