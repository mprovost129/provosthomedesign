Connection setup for the website administrator

Use a Stripe sandbox, not live keys. Configure the web service and scheduled job with NATIVE_STRIPE_TEST_SECRET_KEY, NATIVE_STRIPE_TEST_WEBHOOK_SECRET, then enable NATIVE_STRIPE_TEST_ENABLED. Keep credentials in private hosting settings.

Webhook address: https://www.provosthomedesign.com/billing-test/stripe/webhook/. Subscribe to checkout completion, asynchronous success/failure, checkout expiration, refunds and disputes. Full setup and event names are in the release documentation.

No live-mode switch exists in this release. Sandbox testing does not authorize actual client charges or a FreshBooks cutover.
